# Публикация Android

Публикуйте подписанные APK TnDtun для ARM64 в открытых GitHub Releases репозитория
`Stepan-Gribov/vpn-android`. Собирайте APK из актуальных проверенных исходников
с установленным идентификатором приложения и тем же ключом подписи для обновлений.

Рабочие профили, пароли, приватные и общие ключи не должны попадать в APK.
Приложение получает параметры подключения через подписку. В APK могут входить
публичные адреса API и публичные ключи проверки.

Публикуйте один ARM64 APK на выпуск. Укажите версию и SHA‑256 в описании.
Скачайте APK через публичную ссылку без авторизации и сверьте хеш.
