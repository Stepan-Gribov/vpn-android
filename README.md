# VPNApp для Android

Исходники Android-мини-приложения TnDtun. Клиент на Kotlin сохраняет и импортирует профили, показывает состояние соединения и управляет раздельной маршрутизацией. В проект входят Android VPN Service, адаптеры транспортов и Java-компоненты AmneziaWG.

Публичная ветка основана на снимке Android 0.1.4 (build 38). Обновление синхронизации имеет номер сборки 42. Настройки серверов заменены примерами, проверка пользователя проходит вручную. Для подключения введите параметры собственного сервера. Панель подписок и готовый профиль DNS требуют отдельной настройки.

## Обновление подписок

Панель включает автообновление для каждой подписки через поле
`settings.subscriptionSync` в подписанном пакете. Допустимый интервал
от 15 до 1440 минут. Когда политика отсутствует или отключена, обновление
доступно вручную. Под кнопкой **Обновить** отображается локальное время
последнего успешного получения настроек.

Android планирует фоновую работу через WorkManager при наличии сети.
Если система отложила работу, приложение также проверяет срок при возврате
на любой экран. Принудительная остановка приложения откладывает фоновую
работу до следующего запуска.

## Локальная сборка

Откройте папку [V2rayNG](V2rayNG/) в Android Studio. Нужны Android SDK 37, JDK 17 и Gradle Wrapper проекта. Для сборки потребуются совместимый `libv2ray.aar` и нативные библиотеки transport helpers для нужной архитектуры, размещённые локально в `V2rayNG/app/libs/` и её подпапках ABI. Это снимок исходников, готовые библиотеки и APK в него не входят.
