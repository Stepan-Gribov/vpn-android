# VPNApp для Android

Исходники Android-мини-приложения TnDtun. Клиент на Kotlin сохраняет и импортирует профили, показывает состояние соединения и управляет раздельной маршрутизацией. В проект входят Android VPN Service, адаптеры транспортов и Java-компоненты AmneziaWG.

Публичный снимок исходников основан на Android 0.1.4 (build 38) и включает обновление подписок из сборки 42. Настройки серверов в этом снимке заменены примерами.

## Скачать Android APK

Стабильные подписанные APK для ARM64 публикуются в открытом разделе Releases. После установки откройте «Добавить подписку» и введите выданный код. Приложение получает профили и настройки в подписанном пакете панели. [Релизы Android](https://github.com/Stepan-Gribov/vpn-android/releases/latest)

## Обновление подписок

Панель включает автообновление для каждой подписки через поле
`settings.subscriptionSync` в подписанном пакете. Допустимый интервал
от 15 до 1440 минут. Когда политика отсутствует или отключена, обновление
доступно вручную. Под кнопкой **Обновить** отображается локальное время
последнего успешного получения настроек.

Android планирует фоновую работу через WorkManager при наличии сети.
Если система отложила работу, приложение также проверяет срок при возврате
на любой экран. Принудительная остановка приложения откладывает фоновую
работу до следующего запуска.

## Временная полная маршрутизация

При переключении «Всё в туннель» приложение перестраивает интерфейс и
правила в текущем VPN-сервисе. Если новый режим не запускается, приложение
один раз пытается восстановить предыдущую маршрутизацию. Для Amnezia
сплит-туннель включён по умолчанию, а сохранённое значение переключателя
сохраняется при обновлении.

Эмуляторная проверка использует синтетический профиль TURN. Она проверяет
переключение в обе стороны и откат при ошибке старта. Отдельный локальный
HTTPS-тест проверил выбор прямого и прокси-маршрутов через Android TUN, HEV
и Xray. Для подтверждения трафика через реальный VK TURN нужна проверка на
физическом устройстве с действующим профилем.

## Локальная сборка

Откройте папку [V2rayNG](V2rayNG/) в Android Studio. Нужны Android SDK 37, JDK 17 и Gradle Wrapper проекта. Для сборки потребуются совместимый `libv2ray.aar` и нативные библиотеки transport helpers для нужной архитектуры, размещённые локально в `V2rayNG/app/libs/` и её подпапках ABI. Готовые библиотеки предоставляются отдельно.

Клиент основан на [v2rayNG](https://github.com/2dust/v2rayNG).
